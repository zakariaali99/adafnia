Owner rejected v1 as oversimplified and prefers the original's appearance. Request: run original, compare, combine strengths and implement best version. Approved directly by user; implementation proceeds.

## Observed comparison

Original run isolated at127.0.0.1:8770, desktop1440x1000 and mobile390x844. Preserved screenshots in /private/tmp/adafnia-old-desktop.png, adafnia-old-quality.png, adafnia-old-mobile.png. Original source untouched.

V1 visual weaknesses: thin header/type, too much neutral empty space, repetitive text-first sections, weak industrial identity, text-only project/news presentation.

## Chosen design

Dark industrial opening transitions to an airy product catalogue, then a cinematic blue manufacturing chapter, real factory story and projects. Navy #071d30, electric factory blue #075ba6, brand cyan #05afdc, cool white. This is a deliberate alternating chapter design requested as a blend with the original, not a uniform minimal theme.

- Full-bleed original industrial artwork as decorative visual (not documentary claim), large Cairo headline, strong product CTA, compact integrated capability strip with verified catalogue numbers.
- Transparent header over hero switches to solid on scroll; mobile accessible drawer remains.
- Large image-led catalogue cards, stronger product details, technical reference/download CTA.
- Factory story uses actual aerial image and timeline; no fake equipment/manufacturing claims.
- Rich production chapter with factory reference imagery and interactive stage tabs driven by available assets.
- Applications use consistent Phosphor line icons and functional links.
- Certificate presentation uses archival/current state accurately; no fake active ISO badges.
- Project cards show source-backed names/location; no unrelated stock photos.
- News empty state integrates a helpful industrial editorial panel instead of an empty text row.
- Intro becomes a richer industrial/cyan water reveal, retains skip/focus/reduced-motion behavior.
- All inner public pages inherit new typography, page mastheads, cards and footer. Backend/dashboard behavior preserved.
